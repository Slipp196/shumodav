\# 🎙️ Шумодав



Простой голосовой чат для своих: вход по нику, аватарка, мут микрофона,

деф (выключить весь звук), интерфейс на русском и украинском.



Стек: Node.js + Express + Socket.IO + WebRTC (mesh, peer-to-peer).



\## Запуск локально



```bash

npm start
